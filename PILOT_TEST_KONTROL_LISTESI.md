# Arti Destek Portal Pilot Test Kontrol Listesi

Bu liste, canli kullanima gecmeden once portalin admin, personel ve musteri tarafinda gercek senaryo ile denenmesi icin hazirlandi.

## 1. Giris ve Yetki Testleri

- [ ] Admin kullanicisi e-posta ve sifre ile giris yapabiliyor.
- [ ] Admin tum menuleri gorebiliyor.
- [ ] Admin ekleme, duzenleme, silme islemlerini yapabiliyor.
- [ ] Personel kullanicisi sadece kendi ekranlarini gorebiliyor.
- [ ] Personel kendi bordro, ozluk, izin ve mesaj alanlarina ulasabiliyor.
- [ ] Musteri kullanicisi sade musteri portalina giris yapabiliyor.
- [ ] Musteri sadece kendisine ait proje, fatura, rapor ve mesajlari gorebiliyor.
- [ ] Musteri ekleme, duzenleme ve silme islemi yapamiyor.
- [ ] Cikis butonu tum kullanici tiplerinde calisiyor.

## 2. Firma Testleri

- [ ] Yeni firma eklenebiliyor.
- [ ] Firma bilgileri duzenlenebiliyor.
- [ ] Firma silinebiliyor.
- [ ] Firma listesinde arama ve filtreleme calisiyor.
- [ ] Sozlesme dosyasi yuklenebiliyor.
- [ ] Fiyat teklifi dosyasi yuklenebiliyor.
- [ ] Sozlesme / teklif durumu aktif olarak takip edilebiliyor.

## 3. Personel Testleri

- [ ] Yeni personel eklenebiliyor.
- [ ] Personel bilgileri duzenlenebiliyor.
- [ ] Personel aktif / pasif durumu degistirilebiliyor.
- [ ] Aktif personel yesil, pasif personel kirmizi gorunuyor.
- [ ] Personel 360 ekraninda ilgili kayitlar gorunuyor.
- [ ] Personel dosyalari ilgili kisiyle eslesiyor.

## 4. Ozluk Belgeleri Testleri

- [ ] Bir personele ozluk belgesi yuklenebiliyor.
- [ ] Birden fazla dosya yuklenebiliyor.
- [ ] Dosya yuklendikten sonra personel eksik ozluk olarak sayilmiyor.
- [ ] Ozluk kontrol listesi tamamlandi olarak isaretlenebiliyor.
- [ ] Ozluk belgesi indirilebiliyor veya goruntulenebiliyor.
- [ ] Eksik / tamam durumlari dogru renkte gorunuyor.

## 5. Bordro Testleri

- [ ] Yeni bordro kaydi eklenebiliyor.
- [ ] Brut ucret girildiginde net ucret hesaplanabiliyor.
- [ ] Net ucret girildiginde brut ucret hesaplanabiliyor.
- [ ] Avans bilgisi bordroya yansiyor.
- [ ] Banka ve BES bilgileri bordro alaninda takip ediliyor.
- [ ] Bordro PDF olarak indirilebiliyor.
- [ ] PDF ciktisi kurumsal ve okunabilir gorunuyor.
- [ ] Bordro Excel olarak indirilebiliyor.
- [ ] Personel kendi bordrosunu self-servis ekraninda gorebiliyor.

## 6. Puantaj ve Mesai Testleri

- [ ] Personel icin aylik puantaj girilebiliyor.
- [ ] Geldi / gelmedi / raporlu / gecici gorev secenekleri calisiyor.
- [ ] Gunluk manuel saat girisi yapilabiliyor.
- [ ] Mesai saati manuel girilebiliyor.
- [ ] Toplam calisma saati dogru hesaplaniyor.
- [ ] Toplam mesai saati dogru hesaplaniyor.
- [ ] Puantaj bilgileri raporlara yansiyor.

## 7. Proje Testleri

- [ ] Yeni proje eklenebiliyor.
- [ ] Proje kodu AD + plaka mantigi ile otomatik uretiliyor.
- [ ] Proje baslangic tarihi secilebiliyor.
- [ ] Bitis tarihi zorunlu degil.
- [ ] Bitis tarihi girilince durum otomatik pasif oluyor.
- [ ] Proje durumu aktif / pasif / beklemede filtrelenebiliyor.
- [ ] OK / NOK / ROK / NROK adetleri girilebiliyor.
- [ ] OK yesil, NOK kirmizi, ROK mavi, NROK turuncu gorunuyor.
- [ ] Proje grafik ikonu ilgili kalite grafigini aciyor.

## 8. Fatura Testleri

- [ ] Yeni fatura eklenebiliyor.
- [ ] Fatura Kesildi / Fatura Beklemede / Onay Verilmedi durumlari secilebiliyor.
- [ ] Fatura durumuna gore filtreleme calisiyor.
- [ ] KDV orani duzenlenebiliyor.
- [ ] Tevkifatli fatura bilgisi girilebiliyor.
- [ ] IBAN alani genis ve okunabilir gorunuyor.
- [ ] Fatura Excel olarak indirilebiliyor.
- [ ] Fatura PDF olarak indirilebiliyor.

## 9. Mesajlasma Testleri

- [ ] Mesajlar ekrani aciliyor.
- [ ] Kullanici listesi gorunuyor.
- [ ] Online / offline durumu gorunuyor.
- [ ] Admin personele mesaj gonderebiliyor.
- [ ] Personel admin mesajini gorebiliyor.
- [ ] Musteri mesaj gonderebiliyor.
- [ ] Mesaj e-posta bildirimi kuyruguna alinabiliyor.
- [ ] Okunmamis mesaj veya bildirim fark edilebilir gorunuyor.

## 10. Bildirim Merkezi Testleri

- [ ] Yeni bildirim olusturulabiliyor.
- [ ] Bildirim okunmadi olarak basliyor.
- [ ] Bildirim okundu isaretlenebiliyor.
- [ ] Acil bildirimler ayrica gorunuyor.
- [ ] Geciken maas, avans veya odeme uyarisi kirmizi gorunuyor.
- [ ] Tamamlanan bildirimler listede dogru durumla gorunuyor.

## 11. Rapor ve Grafik Testleri

- [ ] Raporlar kisilere gore filtrelenebiliyor.
- [ ] Aylik rapor goruntulenebiliyor.
- [ ] Yillik rapor goruntulenebiliyor.
- [ ] Bordro, avans, mesai ve icra bilgileri grafiklere yansiyor.
- [ ] Dikey grafik calisiyor.
- [ ] Pasta grafik calisiyor.
- [ ] Rapor PDF olarak indirilebiliyor.
- [ ] Rapor Excel olarak indirilebiliyor.

## 12. KVKK ve Veri Saklama Testleri

- [ ] KVKK / veri saklama alani aciliyor.
- [ ] Bordro verisi saklama suresi gorunuyor.
- [ ] Ozluk dosyasi saklama suresi gorunuyor.
- [ ] Musteri portal verisi saklama suresi gorunuyor.
- [ ] Risk seviyesi ve durumlar takip edilebiliyor.
- [ ] Gizlilik alani admin tarafindan duzenlenebiliyor.

## 13. Kurulum Sihirbazi Testleri

- [ ] Firma eklenmeden firma adimi tamamlandi gorunmuyor.
- [ ] Personel eklenmeden personel adimi tamamlandi gorunmuyor.
- [ ] Kullanici acilmadan kullanici adimi tamamlandi gorunmuyor.
- [ ] Bordro / banka / BES bilgisi girilmeden bordro adimi tamamlandi gorunmuyor.
- [ ] Tum zorunlu adimlar tamamlaninca sihirbaz tamamlandi gorunuyor.

## 14. Mobil Testler

- [ ] Telefon giris ekrani duzgun gorunuyor.
- [ ] Telefon ana panelde kayma veya tasma yok.
- [ ] Sol menu mobilde acilip kapanabiliyor.
- [ ] Kartlar ekrana sigiyor.
- [ ] Tablolar mobilde yatay kaydirma ile okunabiliyor.
- [ ] PDF indirme telefonda calisiyor.
- [ ] Mesajlasma telefonda kullanilabiliyor.

## 15. Canli Site Testleri

- [ ] Vercel linki bilgisayarda aciliyor.
- [ ] Vercel linki telefonda aciliyor.
- [ ] Farkli internet agindan giris yapilabiliyor.
- [ ] Supabase girisi canli sitede calisiyor.
- [ ] Dosya yukleme canli sitede calisiyor.
- [ ] Yeni eklenen veri sayfa yenilenince kaybolmuyor.
